# superapp-e2e (Playwright)

Suite pengujian otomatis end-to-end (E2E) menggunakan Playwright untuk memvalidasi alur kritis aplikasi.

---

## Menjalankan Pengujian

```bash
cd superapp-e2e

# Jalankan seluruh test
npx playwright test

# Jalankan dalam mode UI interaktif
npx playwright test --ui
```
