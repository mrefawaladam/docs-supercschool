# superapp-frontend (Next.js)

Aplikasi web modern berbasis Next.js 15, React 19, dan Tailwind CSS.

---

## Menjalankan Service

```bash
# Dari root monorepo
make dev-fe

# Atau langsung dari foldernya
cd superapp-frontend
npm run dev # atau pnpm dev
```

Layanan dapat diakses di `http://localhost:3000`.
