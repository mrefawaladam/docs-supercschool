# Input Buku Nilai & Rekap Rapor

Buku Nilai (Gradebook) menyatukan seluruh komponen penilaian: nilai harian, nilai tugas LMS, nilai ujian CBT, serta penilaian sikap siswa.

---

## 1. Mengisi Nilai Mata Pelajaran

1. Masuk ke menu **Akademik** **Buku Nilai (Gradebook)**.
2. Pilih mata pelajaran dan kelas yang Anda ampu.
3. Anda akan melihat kolom-kolom komponen nilai:
   - Nilai Tugas 1, 2, 3...
   - Nilai Ulangan Harian (UH)
   - Nilai Ujian Tengah Semester (UTS / PTS)
   - Nilai Ujian Akhir Semester (UAS / PAS)
4. *Nilai dari tugas LMS dan ujian CBT dapat ditarik otomatis tanpa perlu mengetik ulang* dengan mengklik tombol **Tarik Nilai Otomatis dari CBT/LMS**.
5. Untuk input manual, cukup ketikkan angka di kolom yang bersangkutan.
6. Klik **Simpan Nilai**.

---

## 2. Bobot Penilaian & Nilai Akhir

Sistem akan secara otomatis menghitung nilai akhir berdasarkan bobot yang ditetapkan kurikulum sekolah (contoh: 30% Tugas + 30% PTS + 40% PAS).

Jika nilai akhir di bawah batas Kriteria Ketercapaian Tujuan Pembelajaran (KKTP / KKM), sistem akan memberi tanda warna oranye sebagai penanda siswa memerlukan program remedial.
