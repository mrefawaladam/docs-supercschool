# Manajemen User & Pengaturan Sistem

Section ini menggabungkan manajemen seluruh akun pengguna (User Management) serta konfigurasi operasional dan identitas sekolah (Settings).

## Daftar Fitur di Section Ini

1. **[Manajemen User (Daftar Pengguna)](/panduan-sistem/manage-users)**: Kelola seluruh akun guru, admin, tata usaha, dan kasir, tambah/edit profil, impor/ekspor Excel, serta reset password.
2. **[Pengaturan Umum Sistem (Settings)](/panduan-sistem/settings)**: Konfigurasi modul aplikasi (logo, nama sekolah, kontak, poin absensi), format cetak nota/struk kasir, serta kustomisasi tema warna sekolah.
